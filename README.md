# 📘 SQL Basics Practice – Step by Step

This repository contains my practice work on **fundamental SQL operations** using a `students` table.  
I documented each step with queries and outputs to make learning more clear and practical.

---

## 🚀 Covered Topics
- **CREATE & INSERT** → building and adding records  
- **UPDATE** → modifying data  
- **DELETE** → removing records  
- **ALTER** → adding new columns  
- **ORDER BY** → sorting results  
- **WHERE** → filtering data  

---

## 📂 Repository Structure
- `queries.sql` → contains all SQL queries step by step  
- `results.txt` → outputs of each query  
- `notes.md` → summary of what I learned
